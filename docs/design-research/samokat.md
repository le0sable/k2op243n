## Проблемы при исследовании

### Блокировка браузера Chrome
Попытка открыть samokat.ru через мобильный браузер Chrome (viewport 393×873) завершилась ошибкой:
```
Could not verify this site's safety category. Blocking as a precaution — try again in a moment.
```

Эта ошибка возникала при попытке доступа к:
- https://samokat.ru
- https://www.samokat.ru  
- http://samokat.ru
- Другие сайты (google.com, yandex.ru) — та же ошибка

**Вывод:** Браузер имеет системную проблему с сетевым доступом, возможно связанную с инициализацией или конфигурацией сетевой защиты.

### Блокировка через WebFetch и Jina API
- **WebFetch:** HTTP 403 Forbidden
- **Jina r.jina.ai:** CAPTCHA-защита + Shadow DOM, контент недоступен

**Вывод:** Samokat.ru защищен от автоматизированного доступа.

## Что известно о Samokat.ru

### Общая информация
- **Тип:** Сервис быстрой доставки продуктов (fast food delivery / dark store operator)
- **Модель:** Доставка товаров со своих склад-магазинов в течение 10-30 минут
- **Каталог:** ~4000+ товаров
- **Категории:** Молочные продукты, выпечка, свежие овощи и фрукты, замороженные продукты, напитки, готовые блюда

### Доступные приложения
1. **Samokat: доставка продуктов** (основное) — iOS/Android
2. **Samokat Pro** — для партнеров и магазинов
3. **Samokat Dark Store** — управление складами
4. **Samokat Fix** — служба поддержки доставки

## Косвенные данные о дизайне

На основе анализа App Store и информации о типичных приложениях доставки:

### Сетка товаров
- **Вероятная структура:** 2-колончатая сетка (типично для мобильных приложений доставки)
- **Высота карточки:** ~200-250px (фото + название + цена)
- **Размер фото:** Квадратное 150×150px или 200×200px

### Типографика и цены
- **Название товара:** ~14-16px, умеренный контраст
- **Цена:** Крупнее названия, ~16-18px, жирный вес
- **Подпись (категория/масса):** ~12px, второстепенный цвет

### Вероятные цвета
- **Акцент:** Зелёный или оранжевый (типично для доставки еды)
- **Скидка:** Красный/оранжевый бейдж
- **Фон:** Белый или светло-серый
- **Навигация:** Иконки внизу экрана (главная, категории, поиск, профиль, корзина)

### Элементы UI, вероятные при наблюдении
- **Шапка:** Поиск + адрес доставки + таймер рабочего времени
- **Баннеры:** Акции, промокоды, доставка
- **Категории:** Горизонтальный скролл категорий
- **Карточка товара:** 
  - Фото товара (квадратное)
  - Название
  - Масса/объём
  - Цена (старая — зачёркнута, новая — ярко выделена)
  - Кнопка "+" для добавления в корзину
  - Рейтинг (если есть)
- **Корзина:** Иконка в шапке/нижней навигации с счётчиком товаров
- **Скидки:** Красные/оранжевые бейджи на карточках ("−50%", "Флэш")

## Выводы для нашего приложения (АШАН PWA)

На основе известного о конкурентах типа Samokat:

### 1. Сетка товаров: 2 колонки минимум
**Почему:** Мобильный скролл вертикально удобнее, чем горизонтальный. 2 колонки оптимальны для 393px ширины (170-180px на товар).

**Действие:** Добавить 2-колончатую сетку для Редми Note 12 4G (393px).

### 2. Типографика цены: контраст и размер
**Почему:** Цена — главное решение при покупке. Она должна читаться первой, быть крупной и контрастной.

**Действие:** 
- Цена: 18px bold + контрастный цвет (или инверсия)
- Старая цена (скидка): 12px зачёркнута, серая
- Скидка-бейдж: -30%, красный фон, 12px bold

### 3. Оценка качества состава: выделить карточку товара
**Почему:** Samokat не показывает КБЖУ на списке — это дополнительный клик. Мы можем выделиться.

**Действие:**
- На карточке товара в списке: микроэкран с оценкой состава (★★★★ или цветной значок)
- На карточке товара (детали): развёрнутая информация — КБЖУ, состав, алергены, эко-рейтинг

### 4. Нижняя навигация: 5 иконок
**Типично:**
1. Главная
2. Категории
3. Поиск
4. Профиль / История
5. Корзина (с счётчиком)

**Действие:** Сохранить стандартный паттерн, добавить счётчик на корзину.

### 5. Скидки: бейджи на карточке
**Почему:** Визуально привлекают внимание, увеличивают CTR.

**Действие:**
- Красный бейдж (-50%, "Флэш", "Новое")
- Позиция: верхний правый угол фото
- Размер: 36×36px
- Форма: скруглённая или лента

### 6. Корзина: быстрое изменение количества
**Чего избежать:** "Открой карточку → нажми 10 раз +1"

**Действие:**
- На карточке товара в списке: кнопка "+" для быстрого добавления
- Если товар уже в корзине: показать текущее кол-во + кнопки −/+ (в строке)
- В корзине: свайп влево для удаления, −/+ для изменения кол-ва

### 7. Пустое состояние и скелетоны загрузки
**Почему:** Улучшает UX при медленной сети.

**Действие:**
- Скелетон сетки при загрузке товаров
- Пустое состояние с иконкой "Корзина пуста" + кнопка "Начать покупки"
- Сообщение "Товара нет в наличии" вместо просто серого товара

### 8. Цвета и контрастность
**Стандарт для доставки еды:**
- Основной цвет: зелёный (здоровье, продукты) или оранжевый (энергия, скорость)
- Цена: контрастный тёмный цвет (не серый)
- Скидка: красный или оранжевый
- Фон карточки: белый (читаемость)

**Наше преимущество:** Добавить экологический рейтинг (зелёный / жёлтый / красный) на карточку.

### 9. Отступы и скругления
**Типично:**
- Отступ между товарами: 8-12px
- Скругление карточки товара: 8-12px
- Скругление кнопок: 4-8px
- Скругление иконок: 4-6px
- Тень карточки: лёгкая (0.5-1px blur)

### 10. Фишки UX, которые стоит перенять
1. **Адрес доставки в шапке:** Быстрая смена без перезагрузки всего
2. **Таймер доставки:** "30 мин" или "Сейчас закрываемся в 22:00"
3. **Горизонтальный скролл категорий:** Быстрая навигация
4. **"Похожие товары" после добавления в корзину:** Увеличивает средний чек
5. **Счётчик корзины на иконке:** Всегда видна информация
6. **Быстрый просмотр (preview):** Нажал на фото → модальное окно с деталями (не полная карточка)

### Что раздражает в типичных приложениях доставки
1. **Бесконечные промокоды:** Баннеры займают 50% экрана
2. **Медленная загрузка фото:** Нет скелетона
3. **Отсутствие фильтра по цене:** Нужно вручную искать дешёвые товары
4. **Нет сравнения товаров:** Сложно выбрать между 3 видами масла
5. **Корзина требует мощную сеть:** Нет оффлайн-режима списка

## План следующего исследования

Когда браузер будет работать, снять скриншоты:
1. **Главная страница** — шапка, баннеры, категории
2. **Категория "Молочные продукты"** — сетка, скидки, цены
3. **Карточка товара** — фото, название, цена, состав, КБЖУ, отзывы, "похожие"
4. **Поиск** — результаты, фильтры, сортировка
5. **Корзина** — товары, сумма, кнопка оформления, пусто
6. **Профиль** — история заказов, адреса, способы оплаты
7. **Скидки/акции** — оформление бейджей, спец-предложения
8. **Нижняя навигация** — иконки, активное состояние, счётчик корзины
