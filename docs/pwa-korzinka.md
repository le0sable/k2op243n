# PWA «Корзинка» — устройство и текущее состояние

Мобильный помощник покупок (АШАН Симферополь). Статическая PWA в `web/`,
без сборщиков: `index.html` + `style.css` + `app.js` + `sw.js`.
Данные генерирует `build_site_data.py` из parquet-срезов в `web/data/`.
Локальный запуск: `python -m http.server 8766 --directory web`
(есть конфиг `.claude/launch.json`, имя `korzinka`).

## Экраны

| вкладка | что там |
|---|---|
| Каталог | плитки разделов тематическими группами («Скидки», «Свежее», «Каждый день», «К чаю и перекус», «Остальное»); тап → список товаров раздела со sticky-чипами подкатегорий (k2); поиск с корня — по всему ассортименту |
| Список | список покупок: степперы, бюджет с прогресс-баром и превышением, undo «Вернуть» 5 сек при удалении |
| Любимое | сетка, сгруппированная заголовками разделов, «очистить всё» с подтверждением |
| Моё | скрытые бренды/товары (аккордеоны, «вернуть все»), блок о данных |

Шторка товара: цена/обычная цена/дата конца скидки, шкала оценки состава +
перцентиль, флаги, Е-добавки цветом по вредности (6 видимых + «ещё N»),
КБЖУ, график цены (скрыт при <3 точек или плоской истории), похожие
(горизонталь, «качество за рубль»), «Скрыть товар/бренд», CTA «В список».

## Ключевые механики (app.js)

- **Индекс**: `data/index.json` — колоночный (`cols`+`rows`), разворачивается
  в объекты с короткими ключами: `c` code, `t` title, `b` brand, `k1/k2`
  категории, `p/op/d/de` цена/старая/скидка%/конец, `pk/un` цена за кг/л,
  `r/rc` рейтинг/отзывы, `s/sp` оценка состава/перцентиль, `fl` флаги,
  `st` наличие, `kc/pr` ккал/белки, `typ/rel` типичная цена/отклонение%, `v`
  качество за рубль, `im` URL фото (первый из списка).
- **Детали**: `data/details/N.json`, шард = `сумма кодов символов code % 32`
  (та же формула в `build_site_data.py`, менять синхронно!).
- **Умная скидка**: `isDeal = d>0 && rel<=-5` (rel — отклонение цены от
  медианной «типичной» по истории). Бейдж «цена как обычно» при rel>=-1.
- **Сортировка-комбинатор**: несколько критериев (`rel, r, s, v, pk, p`);
  каждому — перцентильный ранг в текущей выборке, итог = сумма рангов.
  Рейтинг демпфируется числом отзывов: `r * min(rc,20)/20`. Выбор в
  localStorage (`sortSel`), последний критерий снять нельзя.
- **Группы каталога**: словарь `GROUPS` в начале app.js (имя, цвет, список k1).
- **Личное** в localStorage: `cart`, `fav`, `blP`, `blB`, `budget`, `sortSel`.
- **Деструктив** — двухтапный паттерн `data-sure` («точно?», 3 сек).

## Трафик и кэш (sw.js)

- `shell-*` — оболочка cache-first; `data-*` — данные network-first с
  фолбэком; `img-*` — фото auchan.ru cache-first с FIFO-обрезкой до 600 ключей.
- Фото только с `https://www.auchan.ru/files/original/<id>` (35–620 КБ,
  уменьшенных на CDN НЕТ — `/thumbnail/` и размеры дают 404).
- Ленивая догрузка: `data-src` + IntersectionObserver (rootMargin 600px),
  MutationObserver подхватывает новые узлы; заглушка снимается классом `.ok`
  (событие load + фоновый досмотр раз в секунду).
- **При любой правке web/ поднимать версию кэшей в sw.js** (сейчас v9),
  иначе у пользователя залипнет старая оболочка.

## Дизайн

Эталон — Яндекс Лавка, только светлая тема (тёмной НЕТ по решению
пользователя). Токены в `:root` style.css: фон #FFFFFF, текст #212120,
вторичный #999999, акцент #009860 (только кнопки действия), скидка #EF544A,
чипы rgba(101,92,78,.1), радиусы 16px (мелкие 8px), цена 20px/800,
названия 13px/2 строки, заголовки 20px/800. Пастель плиток — по группе,
не по плитке. Исследования конкурентов: `docs/design-research/`,
дизайн-док: `docs/design/design-doc.md`.

## Рабочий процесс с агентами (сложился, придерживаться)

1. Исследование конкурентов — **Haiku** + встроенный браузер (скриншоты,
   getComputedStyle), мобильная эмуляция 393×873 (Redmi Note 12 4G).
2. Реализация — **Opus**, обязателен самопрогон кликами + read_console_messages
   (ноль JS-ошибок) + скриншоты; в своей вкладке (tabs_create, tabId везде).
3. Независимая приёмка — **Sonnet (effort medium)**: чистое состояние,
   все сценарии, регрессии, network-проверка трафика.
4. Фиксы по приёмке и коммит — после каждого цикла.

Замечено в тестовой среде: скриншоты работают только при открытой панели
браузера; фоновые вкладки не грузят lazy-картинки; сетевые ERR_HTTP2/таймауты
картинок auchan.ru — шум песочницы, не дефект.

## Известные хвосты / некст-степы

- Публикация: GitHub Pages (`update_daily.ps1` пушит gh-pages) — remote ещё
  не настроен; альтернатива «только для себя» — Cloudflare Pages + Access.
- `data/index.json` 6,6 МБ — на хостинге обязателен gzip/brotli; дальше можно
  дробить индекс.
- История цен всего 2 дня — «умные скидки» станут честными после недели+
  ежедневных прогонов (`update_daily.ps1` в планировщик).
- Идеи скоринга: строгий флаг «сахар первым ингредиентом», суммирование
  сахара под разными именами (сахар+патока+сироп).
- Связка с проектом цен рынка «Привоз» — в планах.
