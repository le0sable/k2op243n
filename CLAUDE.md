# Парсер каталога АШАН — Симферополь

Выгрузка каталога auchan.ru в JSON/Parquet по магазину **АШАН Симферополь**
(`merchantId=729`, регион Крым `regionId=9`) и ежедневная история цен.

Только сбор данных: выгрузки и снимки цен лежат в `output/`, обработка и
приложения поверх них — вне этого репозитория.

**Перед правками читать `API.md`** — эндпоинты, схемы запросов, подводные камни
API. Файл лежит рядом локально, но в git не хранится (он в `.gitignore`).

## Как это работает

Данные берутся из внутреннего JSON API сайта `/v3/` обычными HTTP-запросами.
**Браузер не нужен** и в зависимостях его нет: HTML сайта закрыт защитой Qrator,
а API — нет, и он разрешён в `robots.txt`. По каждому товару собирается всё, что
отдаёт API: цены и скидки, наличие, бренд, состав, масса, КБЖУ, характеристики,
описание, изображения, кэшбэк, рейтинг и при необходимости сами отзывы.

Проект нацелен на **наблюдение во времени**, а не разовый срез: пищевые категории
собираются ежедневно, весь каталог — раз в неделю.

## Скрипты

| файл | охват | раскладка |
|---|---|---|
| [auchan_parser.py](auchan_parser.py) | одна категория (+ общий API-клиент) | один файл |
| [parse_all_categories.py](parse_all_categories.py) | весь каталог | файл на категорию |
| [parse_food_categories.py](parse_food_categories.py) | только пищевые | файл на категорию |
| [parse_food.py](parse_food.py) | только пищевые (+ список `FOOD_ROOTS`) | всё одним файлом |
| [export_parquet.py](export_parquet.py) | — | конвертация выгрузки в Parquet |
| [snapshot_prices.py](snapshot_prices.py) | пищевые, только цены | один Parquet за день |

```bash
python auchan_parser.py moloko                     # одна категория
python parse_food.py --from-dir output/ГГГГ-ММ-ДД  # пищевой срез из готовой выгрузки
python parse_all_categories.py --reviews           # + тексты отзывов (долго и тяжело)
python export_parquet.py output/food-ГГГГ-ММ-ДД    # Parquet для анализа
python snapshot_prices.py                          # снимок цен за сегодня (~30 сек)
```

Зависимости: `pip install -r requirements.txt` (парсерам нужен только `requests`,
снимку и Parquet — ещё `pandas` и `pyarrow`).

**Снимок цен против полного среза.** Полный обход дёргает карточку каждого товара
(~20 тысяч GET, ~20 мин) ради состава, КБЖУ и характеристик — а они неделями не
меняются. Цена, скидка с датами и остаток лежат уже в листинге категории, поэтому
ежедневный снимок обходится одним POST на страницу категории: ~30 секунд и 250 КБ
на весь пищевой каталог. Отсюда разделение: снимок — ежедневно, полный срез — раз
в неделю. Оговорка: листинг возвращает **только товары в наличии**, поэтому в
снимке их меньше (13 тыс. против 18 тыс.). Отсутствие кода в снимке и означает
«в этот день товара не было»; товары не в наличии добираются только полным срезом
(обход кодов через мерчанта Москвы, см. `API.md`, §6).

Куда пишется результат:

| скрипт | путь |
|---|---|
| `auchan_parser.py` | `output/<категория>_simferopol.json.gz` |
| `parse_all_categories.py` | `output/ГГГГ-ММ-ДД/<категория>.json.gz` + `_manifest.json` |
| `parse_food_categories.py` | `output/food-ГГГГ-ММ-ДД/<категория>.json.gz` + `_manifest.json` |
| `parse_food.py` | `output/food_simferopol_ГГГГ-ММ-ДД.json.gz` |
| `snapshot_prices.py` | `output/snapshots/ГГГГ-ММ-ДД.parquet` — **единственное, что хранится в git** |

Выгрузки сжимаются gzip'ом (в ~8 раз), Parquet ещё в 10 раз меньше. Пищевой срез —
19 продуктовых разделов (`FOOD_ROOTS` в `parse_food.py`), алкоголь отключается
флагом `--no-alcohol`. Полный обход возобновляемый: прерванный прогон продолжается
с той же точки, даже если за это время сменилась дата.

## Автоматический сбор (GitHub Actions)

Историю цен нельзя добрать задним числом: API отдаёт только цену «на сейчас»,
пропущенный день теряется навсегда. Поэтому сбор вынесен в облако и не зависит
от того, включён ли ПК.

| workflow | когда | что делает |
|---|---|---|
| [snapshot.yml](.github/workflows/snapshot.yml) | ежедневно 07:00 MSK | `snapshot_prices.py` → коммит `output/snapshots/ГГГГ-ММ-ДД.parquet` |
| [weekly-full.yml](.github/workflows/weekly-full.yml) | понедельник 03:00 MSK (+ два досбора) | полный пищевой срез → Parquet → релиз `weekly-full` (последние 4 недели) |

Репозиторий публичный, минуты Actions бесплатны без лимита. Подводные камни:

- Гео-блока нет — API отвечает на запросы из зарубежных дата-центров.
- Крон Actions идёт по UTC и под нагрузкой опаздывает на часы.
- Расписание **отключается после 60 дней без активности в репозитории**, и
  коммиты самого бота активностью не считаются. Если сбор встал — проверять
  это первым делом (любой push от владельца сбрасывает счётчик).
- Прогоны `weekly-full` по вторникам и во второй половине понедельника — досбор:
  если основной прогон всё собрал, они длятся ~1 минуту и просто ещё раз
  публикуют срез.
