# Хендофф: приложение списка покупок с ценой за килограмм и оценкой состава

## О чём это

Мобильное приложение (Android-first) для планирования продуктовой закупки. Три опоры продукта:

1. **Цена за килограмм/литр/штуку** стоит рядом с ценой на каждой карточке — сравнение упаковок разного веса без калькулятора.
2. **Оценка состава буквой A–E** (шкала Nutri-Score-подобная) на фото товара, с расшифровкой в шторке.
3. **Итог списка против бюджета** — сумма, полоса заполнения бюджета, «осталось / перерасход», экономия по скидкам.

Плюс личные исключения (ингредиенты и бренды, которые пользователь не хочет видеть) с двумя режимами: скрывать или помечать.

## О файлах в этом бандле

Файлы в бандле — **дизайн-референсы, сделанные в HTML**. Это прототип внешнего вида и поведения, а не продакшн-код для копирования. Задача — **воссоздать эти экраны в среде целевой кодовой базы** (React Native, Compose, SwiftUI, что используется) по её собственным паттернам и библиотекам. Если среды ещё нет — выбрать подходящий фреймворк и реализовать там.

Технически прототип — один компонент с шаблоном и классом логики; вся стилизация инлайновая. Не переносите эту структуру, переносите значения.

## Уровень проработки

**Высокий (hi-fi).** Цвета, типографика, отступы, радиусы, тайминги анимаций — финальные, воспроизводить точно. Исключение: **фотографии товаров и картинки плиток каталога — серые заглушки** (`#F5F4F2`), реальные изображения подставляются при вёрстке. Данные о товарах — восемь демонстрационных позиций, реальный каталог приходит с бэкенда.

## Экраны

Пять корневых экранов + три модальные шторки. Таб-бар из четырёх вкладок: Каталог, Список, Избранное, Моё. Экран «Лента категории» живёт внутри вкладки «Каталог» (таб подсвечен «Каталог»).

### 1. Онбординг

Показывается один раз до входа в приложение, таб-бара нет.

- Заголовок 28/1.15, вес 800, letter-spacing −0.02em: «Список покупок, который считает деньги»
- Подзаголовок 14/1.55 `#5C5B58`
- Секция «БЮДЖЕТ НА ЗАКУПКУ» — оверлайн 11px/700/`.06em`/uppercase `#8A8880`
- Сегмент-контрол на четыре позиции: 2 000 ₽ / 3 000 ₽ / 5 000 ₽ / Свой. Выбор «Свой» раскрывает числовое поле (высота 44, радиус 14, бордер `#EBEAE7`)
- Секция «ЧЕГО НЕ ПОКАЗЫВАТЬ» — горизонтальный ряд чипов-подсказок (пунктирный бордер `1px dashed #D1CFC8`, при выборе заливка `#212120`, текст белый, префикс `+` меняется на `✓`)
- Кнопка «Начать» прижата к низу: высота 52, радиус 16, фон `#212120`, текст белый 15/700

Выход: экран «Каталог».

### 2. Каталог

Плитки «прилавками». Шапка — «Каталог» 20/800.

- Каждый прилавок: заголовок 19/800 + сетка 2 колонки, `gap: 8px`, строки фиксированные `128px`
- Плитка: радиус 14, фон группы, внутренняя сетка `44px / 84px` — верхняя ячейка название 13/600/1.25, нижняя пустая под картинку
- Часть плиток занимает две колонки (`grid-column: span 2`)
- Фоны прилавков: Молочный `#CBE0F5`, Булочная `#F7DCB4`, Овощи и фрукты `#D3E9BC`

Тап по плитке → лента категории.

### 3. Лента категории

Самый плотный экран. Шапка составная и частично сворачивается при скролле.

**Шапка (сворачиваемая часть, max-height 104px):**
- Кнопка «‹» 36×36 + название категории 20/800
- Поиск: высота 40, радиус 16, фон `rgba(101,92,78,.1)`, при фокусе фон `#F5F4F2` и `inset 0 0 0 2px #212120`; крестик очистки справа

**Сегменты сортировки (всегда видны):**
- Три сегмента: «Дешевле · За кг · Состав» + текстовая кнопка «ещё» справа
- Дорожка `rgba(101,92,78,.1)`, радиус 16, паддинг 3
- Белая плашка-указатель едет к выбранному сегменту: `left` c переходом `.34s cubic-bezier(.2,.9,.3,1)`, ширина 33.3333%, радиус 13, тень `0 1px 3px rgba(33,32,31,.12)`
- Цвет подписи переливается: активная `#212120`, неактивная `#5C5B58`, `transition: color .24s`

**Чипы фильтров (сворачиваемая часть, max-height 74px):**
- «В наличии», «Со скидкой» — тумблеры: выкл `rgba(101,92,78,.1)`/`#212120`, вкл `#212120`/`#fff`
- Чип оценки состава (появляется из фильтров) — с крестиком, анимация `popIn`
- Строка «{сортировка} · найдено {N}» 12px `#8A8880`

**Свёртка шапки:** при `scrollTop > 56` — свернуть, при `< 16` — развернуть. Переход `max-height .3s ease-out, opacity .22s ease-out`.

**Сетка товаров:** 2 колонки, `gap: 16px 8px`, карточки выравниваются по общей сетке (`grid-template-rows: subgrid`, `grid-row: span 4`, или span 5 если в выдаче есть заблокированные товары с кнопкой «Показать всё равно») — карточки в ряду выровнены по самой длинной строке названия.

**Карточка товара:**
- Фото 1:1, фон-заглушка `#F5F4F2`, без радиуса
- Буква состава: слева сверху, 28×28, радиус 9, 15/800. Цвета: A `#038141`/бел, B `#85BB2F`/бел, C `#FECB02`/`#212120`, D `#EE8100`/бел, E `#E63E11`/бел
- Бейджи скидки слева снизу, столбиком: экономия `#212120`/бел и процент `#EF544A`/бел, оба радиус 8, 11/700
- «Нет в наличии» — плашка `rgba(33,32,31,.72)`
- Причина исключения — плашка на всю ширину `rgba(33,32,31,.78)`, карточка приглушена до `opacity .55`, снизу кнопка «Показать всё равно»
- Кнопка «+» справа снизу: 36×36, круг, `#212120`, тень `0 2px 8px rgba(33,32,31,.24)`. После добавления превращается в счётчик: тёмная пилюля высотой 36, кнопки −/+ по 32, цифра по центру
- Название 13/1.35, отступ сверху 8
- Цена 19/800/−0.02em в одной строке с зачёркнутой старой (13px `#999`). Цвет цены: со скидкой `#EF544A`, нет в наличии `#5C5B58`, обычная `#212120`
- Под ценой строка «{цена за кг} · ★ {рейтинг}» 12px `#999`

**Состояния:** скелетон 6 карточек с бегущим бликом; пустая выдача — заголовок «Ничего не нашлось», активные условия чипами с крестиком и кнопка «Сбросить все условия».

### 4. Список покупок

**Пустое состояние:** заголовок «Список пока пуст», две строки-действия (повторить прошлую закупку, выбрать другой список) в рамке `1px #EBEAE7`, радиус 16, высота 52; кнопка «Открыть каталог».

**Заполненный, шапка:**
- Название активного списка 20/800 с треугольником `▾` — открывает шторку «Мои списки»
- Тумблер «В магазине / Дома» справа
- Сумма 24/800 с моноширинными цифрами слева, «осталось {N} ₽» / «перерасход {N} ₽» справа (`#00794C` / `#EF544A`)
- Полоса бюджета: высота 8, радиус 4, фон `rgba(101,92,78,.12)`, заполнение `#009860` / `#EF544A` при перерасходе, ширина `transition: width .18s linear`
- Строка «экономия {N} ₽» плашкой + «{N} товаров · бюджет {N} ₽»

**Строка товара:** чекбокс 24×24 радиус 8 (только в режиме «В магазине»), миниатюра 60×60 радиус 8 с буквой состава 20×20, название 13/1.3, сумма позиции 15/800, подстрока «было {N} · −{N}» или цена за кг, счётчик −/+ справа. Отмеченный товар: название зачёркнуто, всё приглушено до `#B9B7B2`.

**Удаление с возвратом:** при уменьшении до нуля строка остаётся с кнопкой «Вернуть» и исчезает через 4 секунды.

**Режим «В магазине»** добавляет нижнюю панель: кнопка «Закупка завершена» (`#009860`, высота 50) и подпись «отмечено N из M · список уйдёт в историю». Нажатие переносит список в историю и очищает текущий.

### 5. Избранное

Оверлайн «ОТДЕЛЬНЫЕ ТОВАРЫ · {N}» и та же сетка карточек, что в ленте, плюс сердечко 44×44 в правом верхнем углу фото (белая drop-shadow-подложка для читаемости на фото). Снятое избранное остаётся на экране до ухода с вкладки, чтобы отмену можно было откатить.

### 6. Моё

Четыре секции, разделённые оверлайнами:
- **Бюджет на закупку** — тот же сегмент-контрол, что в онбординге
- **Личные исключения** — чипы-подсказки, список исключений строками с крестиком 32×32, счётчик «Под правила попадает товаров: N»
- **История закупок** — строки «дата / список · N товаров · сумма» + кнопка «Повторить»
- **Что делать с исключённым** — сегмент на две позиции «Скрывать / Помечать» с пояснением под ним

### Шторки

Все три: `position: absolute`, приклеены к низу, радиус `22px 22px 0 0`, тень `0 -8px 30px rgba(33,32,31,.22)`, выезд через `transform: translateY(110% → 0)` с `.4s cubic-bezier(.22,.9,.28,1)`. Подложка `rgba(33,32,31,.42)`, `opacity .3s ease-out`, закрывается тапом.

**Шторка товара** (высота 704): ручка 44×4, фото 1:1 радиус 12 с буквой состава 34×34 и бейджами скидки, название 17/700, «★ рейтинг · бренд», цена 26/800 со старой ценой и ценой за кг, разделитель, строка «Оценка состава {N} из 100», плюс и минус состава (`+` `#00794C`, `−` `#C07A12`), пунктирная кнопка «Скрывать {ингредиент}». Нижняя панель: сердечко 52×52 (фон `#FDE9E5` в активном) и кнопка «В список · {цена}» / «В списке · {N}».

**Мои списки:** активный список карточкой `#212120` с подписью «активный», сохранённые — `rgba(101,92,78,.1)` с «сделать активным». Активным может быть один; прежний сохраняется.

**Ещё (фильтры):** радиогруппа «Порядок» из четырёх сортировок (индикатор 20×20 радиус 7), «Оценка состава не ниже» — четыре кнопки Любой/A/B/C, кнопка «Показать {N}».

## Взаимодействия и анимации

Все переходы `ease-out`, если не указано иначе. Уважать `prefers-reduced-motion: reduce` — глушить до 0.01ms.

| Что | Как |
|---|---|
| Вход экрана | `screenIn` — opacity 0→1, translateY 8→0, `.32s` |
| Переход между вкладками | направленный: вправо `slideInR` (translateX 22→0), влево `slideInL`, `.3s`. Направление по порядку вкладок |
| Шапка | `headIn` — opacity 0→1, translateY −6→0, `.28s` |
| Плитки каталога и карточки ленты | `tileIn` — opacity 0→1, translateY 10→0, scale .985→1, `.34s`, каскад по 40–45ms, потолок задержки 320ms |
| Строки списка | `rowIn` — opacity 0→1, translateY −6→0, `.3s` |
| Скелетон | бегущий блик: `linear-gradient(100deg, #F0EFEC 30%, #E4E3DE 45%, #F0EFEC 60%)`, `background-size: 260% 100%`, `sweep 1.5s linear infinite`, каскад 90ms |
| Плашка сегментов / бюджета / вкладок | сдвиг `left` за `.34s cubic-bezier(.2,.9,.3,1)`, подписи `color .24s` |
| Счётчик количества | цифра перерисовывается по ключу: `qtyPop` — opacity 0→1, translateY 5→0, scale .75→1, `.22s` |
| Кнопка «+», бейдж, чип | `popIn` — scale .55 → 1.08 → 1, `.2–.26s` |
| Сердечко | `heartPop` — scale 1 → 1.32 → .92 → 1, `.4s` |
| Нажатие кнопок | `transform: scale(.88–.98)` за `.13–.16s`; тёмные кнопки дополнительно `filter: brightness(1.25–1.3)` |
| Сумма списка | числовой рамп к новому значению за 420ms, easing `1−(1−t)³` |
| Полоса бюджета | ширина `.18s linear`, цвет `.3s`; при перерасходе пульс `barPulse 1.8s ease-in-out infinite` (opacity 1 ↔ .5) |
| Шторки | вверх/вниз `.4s cubic-bezier(.22,.9,.28,1)`, подложка `opacity .3s` |
| Свёртка шапки ленты | `max-height .3s`, `opacity .22s` |

## Состояние

Одно хранилище на приложение:

```
screen           'onboarding'|'catalog'|'feed'|'list'|'fav'|'me'
sheet            null|'product'|'lists'|'filters'
prod             id открытого товара
loading          скелетон ленты (900ms после открытия категории)
feedTitle        название открытой категории
qty              { productId: количество }
order            порядок строк в списке (стабильный, по времени добавления)
pending          { productId: true } — удалённые, ждут 4с на «Вернуть»
checked          { productId: true } — отмечено в режиме «В магазине»
shopMode         boolean
seg              'cheap'|'unit'|'grade'|'rate' — сортировка
stock, sale      boolean — чипы фильтров
minGrade         'any'|'A'|'B'|'C'
query            строка поиска
excluded         [{ name, kind }] — личные исключения
hideMode         'hide'|'mark'
allowed          { productId: true } — «Показать всё равно»
fav              { productId: true }
pendingFav       снятые из избранного, держатся до ухода с вкладки
budget, customBudget
activeName, savedLists, history
headerFull       развёрнутость шапки ленты
dir              направление перехода между вкладками (−1|0|1)
```

**Производные значения** (не хранить): сумма, экономия, остаток бюджета, процент заполнения, отфильтрованная и отсортированная лента, счётчик найденного.

**Правила фильтрации ленты** (в порядке применения): поиск по названию и бренду → «в наличии» → «со скидкой» → минимальная оценка состава → при `hideMode === 'hide'` убрать товары с исключениями. Сортировка: по цене / по цене за единицу / по оценке состава / по рейтингу.

**Форматирование:** цены — два знака после запятой, запятая как разделитель, пробел между тысячами, знак `₽` («1 234,50 ₽»); округлённые суммы без копеек. Цифры везде `font-variant-numeric: tabular-nums`. Склонение «товар / товара / товаров» по русским правилам.

## Ассеты

Собственных изображений нет. Фото товаров и картинки категорий — серые прямоугольники `#F5F4F2`, подставляются реальными при вёрстке. Иконки таб-бара и сердечко — инлайновые SVG, `viewBox 0 0 24 24`, `stroke-width 1.8`, `stroke-linecap/linejoin: round`, 22×22 в контейнере 24×24; активная иконка масштабируется до 1.08. Шрифт Golos Text — Google Fonts.
